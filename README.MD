# lab4-variant09

## Описание проекта

Проект реализует пакет `gradecalc` для расчёта итоговой оценки студента на основе домашних заданий, промежуточного и финального экзамена с учетом весов. Также реализованы функции для применения кривой, определения буквенной оценки и формирования отчёта.

---

## Функции пакета `gradecalc`

- **FinalScore** — вычисляет итоговый балл с проверкой корректности входных данных.  
- **ApplyCurve** — добавляет дополнительные баллы к оценке через указатель.  
- **LetterGrade** — преобразует числовую оценку в буквенную (A, B, C, D, F).  
- **FormatGradeReport** — формирует строку отчёта с информацией о студенте и итоговой оценке.
